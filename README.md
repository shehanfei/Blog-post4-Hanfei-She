# Blog Post 4: Income and Life Expectancy, 1990 to Today

Question: how strong is the cross-country relationship between income and life expectancy
(the Preston curve), and how has it changed since 1990?

## Data
World Bank World Development Indicators (WDI), downloaded via the `WDI` R package (no API key needed):
- `NY.GDP.PCAP.PP.KD`: GDP per capita, PPP, constant 2021 international $
- `SP.DYN.LE00.IN`: life expectancy at birth
- `SP.POP.TOTL`: population (used for bubble size and population-weighted means)

## Structure
```
code/       01_get_data.R, 02_clean_data.R, 03_make_figures.R, run_all.R
data/raw/        raw download (created by script 01)
data/processed/  cleaned data (script 02)
results/figures/ PNG figures (script 03)
results/tables/  regression and gap tables (script 03)
blog_post.qmd    the blog post (reads results from results/)
```

## Replication
1. Install packages: `install.packages(c("WDI","tidyverse","scales","ggrepel","broom","here","knitr"))`
2. Open the project folder in R/RStudio (the `.here` file marks the root).
3. Run `source("code/run_all.R")`.
4. Render the post: `quarto render blog_post.qmd`.

Figures and numbers in the post are all generated by the scripts; nothing is pasted by hand.
